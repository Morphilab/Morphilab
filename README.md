### About me

I'm a software developer based in Mexico and the founder of **Morphilab**, a small open-source lab. My work spans command-line utilities, services, and desktop applications, from systems administration to AI-assisted software engineering.

I care about clear code, reversible operations, and keeping things simple enough to understand. The safe choice should be the default, and the final call should always be the user's.

### Project index

<!-- BEGIN:proyectos -->
`01` · **[ravenhub](https://github.com/Morphilab/ravenhub)** · `Go`

> Centralized notification hub for agents and workflows: one HTTP call, multi-channel delivery (Telegram, email, webhook, Discord, Slack), PostgreSQL queue, retries, audit, and scoped tokens.

`02` · **[copycrow](https://github.com/Morphilab/copycrow)** · `Shell`

> Automated and manual backups with Borg: guided TUI, native systemd timers, client-side encryption, deduplication, configurable retention, atomic per-job locks, and optional Proton Drive offsite replication.

`03` · **[sendorbit](https://github.com/Morphilab/sendorbit)** · `Shell`

> Security-first SSH/SCP/Rsync orchestration with TUI + CLI, automatic backups, input sanitization, and security logging.

`04` · **[TG-Sentry](https://github.com/Morphilab/TG-Sentry)** · `Python`

> Monitor and clean your own Telegram account over MTProto (Telethon): dry-run by default, explicit confirmation, anti-ban limits, full audit, and TUI + CLI.

`05` · **[theduckpurge](https://github.com/Morphilab/theduckpurge)** · `Shell`

> Privacy-first metadata sanitizer for PDFs, images, Office docs, audio, and video: 4 cleaning levels, CLI-only, 100% offline.

`06` · **[thefoxup](https://github.com/Morphilab/thefoxup)** · `Shell`

> Security-first Debian/Ubuntu updater — local and remote via SSH, with YAML config, parallel execution, lock protection, and ShellCheck-validated Bash.

`07` · **[iterecho](https://github.com/Morphilab/iterecho)** · `Python`

> Secure file processor: copy, concatenate, or chunk file trees with security-first validation.

`08` · **[nebulaforge](https://github.com/Morphilab/nebulaforge)** · `Python`

> Forge secure, auditable Conda environments.
